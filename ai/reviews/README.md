# Content Review Checklists

This directory contains quarterly content review checklists generated by the `site-content-review` agent.

## Purpose

The content review system helps keep Let's Talk CDC content current with the rapidly evolving CDC ecosystem, including:

- **Debezium** - Open-source CDC platform
- **Apache Kafka** - Streaming platform
- **Matillion** - Cloud ETL/ELT platform
- **AWS DMS** - Database Migration Service
- **Fivetran** - Managed data integration
- **Oracle GoldenGate** - Enterprise CDC solution

## How It Works

### Automatic Generation

The `site-content-review` agent runs quarterly (January, April, July, October) and:

1. Reads current tool versions from `src/_data/toolVersions.cjs`
2. Generates a comprehensive review checklist
3. Creates an issue with action items
4. Commits the checklist to this directory

### Manual Execution

You can also run the content review manually:

```bash
npm run agent:content-review
```

Or via GitHub Actions:
1. Go to Actions → Quarterly Content Review
2. Click "Run workflow"

## Review Process

When a new checklist is generated:

1. **Review Tool Versions**: Check each tool's release notes for updates
2. **Update Data File**: Modify `src/_data/toolVersions.cjs` with new versions
3. **Update Content**: Update quickstart guides, examples, and documentation
4. **Test Changes**: Verify Docker Compose files and examples still work
5. **Update CHANGELOG**: Document significant changes
6. **Close Issue**: Mark the quarterly review as complete

## Checklist Format

Each checklist includes:

- **Tool Version Checks**: Current versions and release note links
- **Content Update Checklist**: Areas to review (guides, configs, examples)
- **Labs and Hands-on Content**: Testing requirements
- **Documentation Links**: External link validation

## Files

- `content-review-YYYY-MM-DD.md` - Generated quarterly checklists
- Each file is timestamped with generation date

## Maintenance

Review checklists can be archived after completion. Consider keeping the last 4 quarters for reference.
