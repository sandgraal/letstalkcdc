REMAINING SETUP TASKS
------------------------------------------------------------

To enable Appwrite features, you need to:

1. **Create an Appwrite Project** (if not done already):
   - Go to https://cloud.appwrite.io (or your self-hosted instance)
   - Create a new project
   - Note your Project ID

2. **Set Up the Database**:
   - In Appwrite Console, create a database named "main"
   - Import the collections from appwrite.collections.json
   - This creates two collections: "progress" and "events"

3. **Generate API Key** (for server-side function only):
   - In Appwrite Console → Settings → API Keys
   - Create a new API key with database read/write permissions
   - This key is ONLY used by the serverless function
   - Never expose this in the browser!

4. **Configure GitHub OAuth Provider**:
   - In Appwrite Console → Authentication → Providers → GitHub
   - Enter your GitHub OAuth App credentials (Client ID + Secret)
   - Add callback URLs:
     * http://localhost:8080/?auth=success (local dev)
     * http://localhost:8080/?auth=failed (local dev)
     * https://letstalkcdc.github.io/?auth=success (production)
     * https://letstalkcdc.github.io/?auth=failed (production)
   - Or use wildcards: https://letstalkcdc.github.io/*
   - Enable the provider

5. **Configure Environment Variables**:

   A. **Local Development** (.env file):
      - Copy .env.example to .env
      - Fill in your Appwrite credentials:
        ```
        APPWRITE_ENDPOINT=https://cloud.appwrite.io/v1
        APPWRITE_PROJECT=your_actual_project_id
        APPWRITE_DB_ID=main
        COL_PROGRESS_ID=progress
        COL_EVENTS_ID=events
        APPWRITE_API_KEY=your_secret_api_key
        ```
      - Run: `npm run dev`
      - Visit: http://localhost:8080/intro/

   B. **Production Deployment** (GitHub Actions):
      - In GitHub repo → Settings → Secrets and variables → Actions
      - Add repository secrets:
        * APPWRITE_ENDPOINT
        * APPWRITE_PROJECT
        * APPWRITE_DB_ID
        * COL_PROGRESS_ID
        * COL_EVENTS_ID
        * APPWRITE_API_KEY (for serverless function)
      - Update .github/workflows/deploy.yml to pass these to build
      
   C. **Serverless Function Deployment**:
      Choose your platform and configure environment variables:
      
      **Option 1: Vercel**
      - Deploy function to /api/migrateUser.js
      - Add environment variables in Vercel dashboard
      - Update scripts/progress.js line 750 to use /api/migrateUser
      
      **Option 2: Cloudflare Workers**
      - Deploy as Worker function
      - Configure secrets using wrangler
      - Update fetch URL in scripts/progress.js
      
      **Option 3: AWS Lambda**
      - Deploy with API Gateway
      - Configure environment in Lambda console
      - Update fetch URL in scripts/progress.js
      
      **Option 4: Netlify** (legacy)
      - Add environment variables in Netlify site settings
      - Function already configured at /.netlify/functions/migrateUser
      - No code changes needed

------------------------------------------------------------
TROUBLESHOOTING
------------------------------------------------------------

**Issue: Appwrite SDK fails to load**
- Check browser console for network errors
- Verify CDN is accessible: https://cdn.jsdelivr.net/npm/appwrite@13.0.0/dist/esm/appwrite.js
- Check that environment variables are set and injected into HTML

**Issue: OAuth redirect fails**
- Verify callback URLs are whitelisted in Appwrite Console
- Check that GitHub OAuth app is properly configured
- Look for ?auth=failed in URL after redirect
- Check browser console for errors

**Issue: Progress not persisting**
- Verify Appwrite collections exist and have correct schema
- Check browser console for database permission errors
- Verify API key has database read/write permissions
- Check that userId is correctly set

**Issue: Migration fails after login**
- Verify serverless function is deployed and accessible
- Check function logs for errors
- Verify APPWRITE_API_KEY is set in function environment
- Test function directly: POST to /.netlify/functions/migrateUser with { fromUserId, toUserId }

**Issue: Dashboard doesn't show**
- Verify user is authenticated (not anonymous)
- Check that Chart.js is loaded
- Look for JavaScript errors in console
- Verify CDC_MODULES data is present in window object

DEPLOYMENT NOTES
------------------------------------------------------------

**GitHub Pages Deployment:**
- Static site deploys via .github/workflows/deploy.yml
- Serverless function must be deployed separately (see options above)
- Environment variables must be configured in GitHub Actions secrets

**Environment Variables in CI/CD:**
- Add to .github/workflows/deploy.yml:
  ```yaml
  env:
    APPWRITE_ENDPOINT: ${{ secrets.APPWRITE_ENDPOINT }}
    APPWRITE_PROJECT: ${{ secrets.APPWRITE_PROJECT }}
    APPWRITE_DB_ID: ${{ secrets.APPWRITE_DB_ID }}
    COL_PROGRESS_ID: ${{ secrets.COL_PROGRESS_ID }}
    COL_EVENTS_ID: ${{ secrets.COL_EVENTS_ID }}
  ```

**Security Notes:**
- NEVER commit .env file to git
- APPWRITE_API_KEY is server-side ONLY
- Only public config (endpoint, project ID, collection IDs) goes to browser
- Appwrite SDK handles client authentication via sessions
